Common Cyber Threats

Know your enemy — understand and defend against the most common attacks

🎣

Phishing

HIGH RISK

Fraudulent attempts to steal credentials or financial info by impersonating trusted entities via email, SMS, or fake websites.

Prevention Tips:
  • Verify sender email addresses carefully
  • Never click suspicious links
  • Enable multi-factor authentication
  • Use email filtering solutions
🦠

Malware

HIGH RISK

Malicious software including viruses, worms, trojans, ransomware, and spyware designed to damage or gain unauthorized access to systems.

Prevention Tips:
  • Keep software and OS updated
  • Use reputable antivirus software
  • Avoid downloading from untrusted sources
  • Regularly back up important data
🔒

Ransomware

CRITICAL

Ransomware encrypts your files and demands payment for decryption. Often spread via phishing emails or vulnerable software.

Prevention Tips:
  • Maintain offline backups (3-2-1 rule)
  • Patch vulnerabilities promptly
  • Restrict administrative privileges
  • Train employees on phishing
👤

Man-in-the-Middle

MEDIUM RISK

Attackers intercept communications between two parties, eavesdropping or altering data without either party knowing.

Prevention Tips:
  • Always use HTTPS connections
  • Avoid public Wi-Fi for sensitive tasks
  • Use a trusted VPN
  • Verify SSL certificates
💥

DDoS Attack

HIGH RISK

Distributed Denial of Service floods a target server with traffic, making services unavailable to legitimate users.

Prevention Tips:
  • Use CDN and DDoS mitigation services
  • Rate limit incoming traffic
  • Deploy Web Application Firewalls
  • Monitor traffic anomalies
💉

SQL Injection

CRITICAL

Attackers inject malicious SQL code into input fields to manipulate databases, extract data, or bypass authentication.

Prevention Tips:
  • Use parameterized queries / prepared statements
  • Validate and sanitize all user input
  • Apply least privilege to DB accounts
  • Use Web Application Firewalls

Ethical Hacking

Learn the art of authorized penetration testing and vulnerability assessment

What is Ethical Hacking?

Ethical hacking (penetration testing) involves legally breaking into computers and systems to test an organization's defenses. Ethical hackers use the same tools and techniques as malicious hackers, but with explicit permission.

The 5 Phases of Ethical Hacking

01
Reconnaissance

Gather intelligence about the target: OSINT, DNS lookups, social media, Shodan.

02
Scanning

Port scanning (Nmap), vulnerability scanning (Nessus), service enumeration.

03
Gaining Access

Exploit vulnerabilities using tools like Metasploit, SQLmap, or custom exploits.

04
Maintaining Access

Establish persistence via backdoors, rootkits, or scheduled tasks.

05
Reporting

Document findings, CVSS scores, and remediation recommendations.

Network Security

Protect your network infrastructure from threats, intrusions, and unauthorized access

🧱

Firewalls

Packet filtering, stateful inspection, and next-gen firewalls (NGFW) form the first line of defense for network security.

🔍

IDS / IPS

Intrusion Detection and Prevention Systems monitor network traffic for suspicious patterns and can automatically block threats.

🔒

VPN

Virtual Private Networks encrypt network traffic and create secure tunnels between endpoints across untrusted networks.

🌐

DMZ Architecture

A demilitarized zone isolates public-facing servers from the internal network, limiting exposure of sensitive resources.

📡

Network Segmentation

Dividing networks into segments limits lateral movement during breaches and reduces the blast radius of attacks.

🕵️

Packet Analysis

Capture and analyze network packets with tools like Wireshark to detect anomalies, malware C2 traffic, and data exfiltration.

Incident Response Guide

Step-by-step actions when a security incident occurs

1

Preparation

  • Establish an Incident Response Plan (IRP)
  • Form and train the IR team (CSIRT)
  • Deploy logging, SIEM, and alerting tools
  • Conduct tabletop exercises regularly
  • Maintain updated asset inventory
2

Identification

  • Detect anomalies via SIEM alerts or user reports
  • Determine the scope and affected systems
  • Classify incident severity (P1–P4)
  • Preserve logs and initial evidence
  • Notify stakeholders per escalation policy
3

Containment

  • Isolate affected systems from the network
  • Disable compromised accounts immediately
  • Block malicious IPs and domains at firewall/DNS
  • Preserve forensic images before remediation
  • Implement short-term workarounds
4

Eradication

  • Remove malware, backdoors, and rootkits
  • Patch the exploited vulnerability
  • Reset all compromised credentials
  • Verify integrity of critical files and configs
  • Conduct root cause analysis (RCA)
5

Recovery

  • Restore systems from clean, verified backups
  • Monitor closely for signs of re-infection
  • Gradually reconnect systems to production
  • Validate system functionality and security
  • Communicate status updates to stakeholders
6

Lessons Learned

  • Conduct post-incident review (PIR) within 2 weeks
  • Document timeline, actions, and decisions
  • Update IRP, playbooks, and detection rules
  • Share sanitized findings with the team
  • Track metrics: MTTD, MTTR, total impact

Quick Security Tips

Essential habits that keep you safer every day

🔑

Use Strong Passwords

Use 16+ character random passwords. Use a password manager like Bitwarden or 1Password.

📱

Enable 2FA Everywhere

Always enable two-factor authentication. Use an authenticator app rather than SMS when possible.

🔄

Keep Software Updated

Enable automatic updates for OS, browsers, and apps. Patches fix security vulnerabilities.

🌐

Use HTTPS Only

Only enter sensitive data on HTTPS sites. Look for the padlock icon in your browser.

💾

Back Up Your Data

Follow the 3-2-1 rule: 3 copies, 2 formats, 1 offsite/cloud backup.

🔗

Think Before You Click

Hover over links to verify URLs. Be suspicious of urgency, threats, or too-good-to-be-true offers.

📶

Secure Your Wi-Fi

Use WPA3, change default router credentials, and hide your SSID. Use VPN on public Wi-Fi.

🛡️

Check App Permissions

Review and limit app permissions. Revoke access to location, mic, or camera when not needed.
